# EcoDash — African Logistics Simulator

An interactive HTML5 Canvas simulation where you pilot a solar-powered delivery drone over an African township at night, delivering medical supplies to clinics while managing battery and avoiding infrastructure hazards.

## Gameplay

- **Goal:** Deliver medical supplies to clinics while managing your solar battery
- **Controls:**
  - Arrow keys or WASD — move the drone
  - ESC — pause / resume
  - Pause button (top-right) — pause
- **Mechanics:**
  - Battery drains while flying; recharges inside Solar Microgrid Zones
  - Obstacles reduce battery on impact
  - Dynamic day/night cycle affects visuals
  - Crosswind drift adds a physics challenge

## Setup Instructions

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. No installation, build steps, or dependencies required

## Tech Stack

- HTML5 Canvas
- CSS3
- Vanilla JavaScript (ES6+)
